# Журнал изменений

## 0.5.1 — DLP по выбору администратора (14.11.2026)

- DLP по умолчанию не требуется: интерфейс открывается сразу, без ожидания проверки агента.
- Вкладка «Доступ через DLP» в «Пользователи и роли» (только администраторы: создатель, CTO, администратор): переключатель требования для каждого сотрудника. Сервер проверяет права и иерархию (нельзя себя и старших), пишет действие в журнал; для отмеченных рабочие API отвечают 428 до подключения агента.
- API: `GET /api/v1/dlp/requirements`, `PUT /api/v1/dlp/requirements/{user_id}`; хранение — прежние настройки `dlp-required:{id}`, схема БД не менялась.
- Тесты: `tests/test_dlp_requirements.py`.

## 0.5.0 — Office 365, схема подразделений, SuperApp (14.11.2026)

- **Название:** «Supperapp» → «SuperApp» во всём видимом тексте и документации. Технические имена (теги образов на сервере, файлы `supper-*`) сохранены.
- **Безопасность Office 365** вместо мониторинга только Outlook/Entra: приёмник разбирает единый журнал аудита — почта Exchange/Outlook, SharePoint, OneDrive, Teams, Entra ID, Purview DLP (`app/command/office365.py`).
- **10 новых правил:** пересылка почты наружу, экспорт почтового ящика, архив отправлен по почте наружу, массовая загрузка архивов, выгрузка архивов, внешняя ссылка на файл, массовый доступ к почте, массовое удаление писем, внешний гость в Teams, срабатывание DLP. Архивы включают `.zip .rar .7z .tar .gz .pst .ost` и др.
- **Агент** `scripts/pull_office365_audit.py`: Office 365 Management Activity API, непрерывный режим `--watch`, контрольные точки по типам журнала; темы и тексты писем не передаются.
- **Экран «Безопасность Office 365»:** счётчики по сервисам, статус потока, правила, лента с автообновлением каждые 15 с.
- **Главная:** интерактивная схема «Одна система для всех уровней» (департамент → дивизион → 4 подразделения, маршрут демонстрационной заявки); 9 учебных примеров вместо 3, риски и пороги приведены в соответствие с правилами кода.
- **Тесты:** +10 (`tests/test_office365.py`, `tests/test_office365_agent.py`); всего 182 серверных.

## 0.4.0 — «Цифровой рубеж» (14.11.2026, ветка `feat/elite-redesign`)

Точка отката: коммит `0628286`. Бизнес-логика, API, схема БД и роли не менялись.

### Интерфейс
- **Дизайн-система.** `styles/tokens.css` — единые токены цвета, типографики, отступов, радиусов, теней и движения для тёмной и светлой тем. Прежние переменные (`--ultra-*`, `--sa-*`) теперь ссылаются на токены.
- **Общий слой компонентов** `styles/system.css`: боковая панель, шапка, заголовки страниц, панели, кнопки, поля, таблицы, бейджи, пустые состояния, ошибки, загрузка, диалоги, экран входа.
- **Главная страница**: первый экран «Цифровой рубеж» (SVG-сцена с контрольными точками и сигналами, консоль обработки сигнала, проверяемые факты), новые секции «Практическая польза» и «Технологии и надёжность». Все прежние секции, ссылки и якоря сохранены.
- Минимальный размер текста поднят с 8–10 px до 11–12 px; контраст служебного текста ≥ 4,5:1.

### Исправлено
- Нижний блок боковой панели перекрывал пункты меню.
- Шапка на странице «Документы» переносилась на вторую строку; элементы шапки были разной высоты и стиля.
- Баннер геолокации занимал первый экран — теперь компактная строка (содержимое то же).

- На телефоне плавающая кнопка меню перекрывала содержимое, вместо аватара была пустая рамка, кнопка закрытия меню накрывала эмблему.
- На планшете панель не сужалась до иконок, заголовок страницы смещался вправо.

- Дублирующиеся импорты CSS в `command-center.tsx`.

### Производительность
- Иллюстрации и эмблема: PNG 5,3 МБ → WebP 125 КБ.
- Помощник по сайту загружается лениво; код страницы загружается параллельно с проверкой готовности.
- Сжатие gzip для статики и HTML: главная 816 КБ → 256 КБ.
- `Cache-Control: immutable` для файлов с хешем, `no-cache` для HTML.

### Безопасность
- `Content-Security-Policy` (только собственный источник), `Permissions-Policy` (только геолокация), `Cross-Origin-Opener-Policy`, HSTS при HTTPS.
- Ответы API не сжимаются (защита от BREACH).
- Уточнены формулировки на главной: каждое утверждение соответствует коду.
