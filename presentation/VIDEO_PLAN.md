# Презентационный ролик AegisBorder SuperApp — план и статус

Статус на 14.11.2026: **работа приостановлена по просьбе владельца**. Готовы инструменты, озвучка проверена, часть экранов снята.

## Формат

- 1920×1080, 30 fps, MP4 (H.264 + AAC), ~2 минуты.
- Монтаж: кинетическая типографика и сцена «Цифровой рубеж» в стиле сайта + реальные экраны приложения с движением камеры, подсветками и выносками.
- Рендер покадровый: HTML-композиция с функцией `render(t)` → скриншоты Playwright → ffmpeg. Анимация детерминирована, без рывков записи экрана.
- Озвучка: локальный голос Windows OneCore **Microsoft Pavel** (альтернатива — Irina), текст никуда не отправляется. Скрипт: `presentation/tts.ps1`.
- Музыка: синтезированная эмбиент-подложка (numpy), без сторонних треков и прав.
- На экране постоянная пометка: «Учебные синтетические данные. Демонстрационный проект».

## Инструменты

- ffmpeg: пакет `imageio-ffmpeg` (содержит libx264 и aac). Ставится вне проекта:
  `.venv\Scripts\python.exe -m pip install --target <папка> imageio-ffmpeg`, путь к exe — `imageio_ffmpeg.get_ffmpeg_exe()`.
- Озвучка: `powershell -File presentation/tts.ps1 -Voice Pavel -Rate 1.0 -TextFile scene.txt -Out scene.wav`.
- Экраны: `cd frontend && node scripts/capture-presentation.mjs ../presentation/shots`
  (нужен тестовый сервер на `127.0.0.1:8100` с учебными данными: запуск сценариев bruteforce, logs, privileges, copy, night-login, restricted, network; документ расследования по инциденту; PDF-отчёт; записи Office 365 через приёмник m365).

## Что осталось

1. Доснять: workspace, reports, scenarios, audit, dlp (скрипт уже содержит эти шаги).
2. Синтезировать озвучку по сценам; длительность сцены = длительность фразы + 0,6–1 с.
3. Собрать HTML-композицию (`presentation/composition.html`) с `render(t)` и сценами из таблицы.
4. Покадровый рендер → ffmpeg; синтез музыки; сведение голоса и музыки; итоговый MP4 в `presentation/build/`.
5. Просмотреть ключевые кадры, поправить тайминги.
