# Бесплатная публичная демонстрация

Текущий проверенный адрес: [открыть AegisBorder](https://generating-discrimination-statutes-classification.trycloudflare.com). На странице входа нажмите «Попробовать без регистрации».

Для показа без домена используется [Cloudflare Quick Tunnel](https://developers.cloudflare.com/tunnel/get-started/quick-tunnels/). Он выдаёт временный HTTPS-адрес `*.trycloudflare.com` без учётной записи Cloudflare. Компьютер, Docker и туннель должны работать; после перезапуска туннеля адрес меняется. Это площадка для демонстрации, без гарантии непрерывной доступности.

Публичный проект `aegis-public` создаётся отдельно от рабочего локального проекта: другая база, том и пароли. Посетитель нажимает «Попробовать без регистрации» и получает отдельную роль demo. Учебные события, инциденты и материалы изолированы от других посетителей. Сеанс живёт два часа. Корпоративные приёмники посетитель создавать не может. Публичная регистрация по умолчанию выключена в основном приложении.

## Запуск

1. Соберите обычный проект: `docker compose build app`.
2. Создайте отдельные секреты: `python scripts/create_public_demo_env.py`. Повторный запуск сохраняет существующий файл `.env.public-demo`; не публикуйте его.
3. Запустите демонстрацию: `docker compose -p aegis-public --env-file .env.public-demo -f compose.public-demo.yaml up -d`.
4. Найдите адрес в `docker compose -p aegis-public --env-file .env.public-demo -f compose.public-demo.yaml logs tunnel`.
5. Выполните `python scripts/set_public_origin.py`, затем `docker compose -p aegis-public --env-file .env.public-demo -f compose.public-demo.yaml up -d app`. Скрипт записывает HTTPS-адрес в `PUBLIC_ORIGIN`, сохраняя остальные секреты. Это разрешает запросы только от указанного сайта и включает Secure-cookie.
6. Проверьте два независимых посещения: задайте `AEGIS_PUBLIC_URL` и выполните `node scripts/public_demo_smoke.js`.

Остановить публичный доступ: `docker compose -p aegis-public --env-file .env.public-demo -f compose.public-demo.yaml stop tunnel`. Том базы сохраняется. Основной проект на порту 8000 продолжает работать.

## IP и город

IP определяется сервером; заголовки принимаются только от доверенной сети туннеля. После входа браузер автоматически запрашивает разрешение на координаты. При разрешении город приблизительно определяется по локальному справочнику 22 городов Казахстана; при недостаточной точности или вне покрытия город не выдумывается. Координаты не отправляются внешнему геосервису. Отказ не запрещает работу. Это не GeoIP-база и не доказательство физического местоположения.

Для постоянного адреса требуется собственный домен и именованный туннель либо размещение на сервере. [Render Free](https://render.com/docs/free) даёт поддомен, но бесплатная база истекает через 30 дней, а сервис засыпает при отсутствии запросов; это ограничение нужно учитывать при переносе всей системы.
