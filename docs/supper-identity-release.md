# AegisBorder Supper — обновление бренда

Опубликовано на Oracle 15 октября 2026 года по прямому запросу владельца.

Название: **AegisBorder Supper**.

Слоган: **«Цифровое суперприложение для расследования киберинцидентов и защиты информации в Пограничной службе КНБ РК»**.

В заголовках, навигации, экране входа, вступлении, описании сайта и новых PDF-отчётах используется новое название. Слоган вынесен в `frontend/src/lib/brand.ts`. Внутренние маршруты и имена компонентов сохранены для совместимости.

Оформление использует глубокий синий, сдержанный бирюзовый и небольшие золотые акценты эмблем. Оригинальные изображения и надписи эмблем не изменены. В главном блоке, при входе и во вступлении добавлены одноразовое появление и короткий световой проход. Постоянного вращения эмблем нет. При `prefers-reduced-motion` эти анимации отключаются.

«Команда проекта» переименована в «Чат». Презентационный баннер заменён компактным заголовком. Сообщения, каналы и серверные права сохранены; изменены только видимые названия тем: «Общий чат», «Киберинциденты», «Вопросы и помощь». Исторические записи аудита не переписываются.

Проверено: production-сборка TypeScript/Vite, ESLint, 13 frontend-тестов, 103 backend-теста, браузерное отображение названия и слогана, загрузка обеих эмблем, чат, мобильная адаптивность и reduced motion. Проверка production выполнена в настоящем браузере без ошибок JavaScript. Вход администратора и API чата возвращают 200; цепочка аудита валидна.

Материалы: `release/supper-identity/after/` и `release/supper-identity/production/`. Протоколы браузера — `checks.json` в этих папках. Локальная копия предыдущих исходников — `release/supper-identity/before/`.
