# Рабочий этап по Master Development Directive

14 октября 2026 года. Продолжен существующий проект в ветке `feature/superapp-redesign`; исходный SuperApp с эмблемами сохранён в коммите `2c99cec`. Общая точка восстановления — тег `superapp-baseline`, локальные дампы PostgreSQL сохранены. Секреты и пользовательские данные не удалялись.

## Что изменено

- Лендинг: новый главный заголовок и подзаголовок, палитра #05070B / #101827 / #00A6BC / #F5B335, раздел «О проекте», каталог двадцати направлений с фильтрами.
- Мегаменю в публичной и рабочей оболочке: категории, иконки, поиск, доступные переходы, закрытие Escape и управление фокусом. Будущие модули не имеют кнопок имитации.
- Общий реестр `frontend/src/lib/modules.ts` описывает фактические статусы и ограничения. Основные SOC-функции и Workspace продолжают использовать прежние API и базу.
- Публичная символика отключается параметром сборки `VITE_PUBLIC_OFFICIAL_EMBLEMS=false`. Это проверено в отдельной сборке на временном порту 8002, затем проверочный сервер остановлен. Основной сайт сохраняет предоставленные эмблемы. Изображения и текст стороннего сайта не копировались.
- Исправлена последовательность повышения риска: успех должен следовать после события, достигшего порога неудачных входов, закрытый ресурс — после этого успеха. При одинаковом времени порядок определяется ID события. Добавлены три отрицательных/положительных теста: риск 65, 80 и 95; проверяется состав связанных доказательств. Существующие инциденты автоматически не пересчитывались.

## Выполненные команды и проверки

- Проверены Git, Docker/Compose и состояние контейнеров; изучены существующие React-компоненты, API и механизм обнаружения.
- `npm run lint`, `npm test`: ESLint без ошибок, 3 unit-теста.
- `python -m pytest -q`: 65 тестов, включая все сценарии, безопасность, документы и проверку порядка корреляции.
- `python -m ruff check`: серверные проверки стиля без ошибок.
- `docker compose up -d --build`: успешная TypeScript/Vite-сборка и запуск; PostgreSQL-том сохранён.
- Отдельная `VITE_PUBLIC_OFFICIAL_EMBLEMS=false npm run build -- --outDir ../.playwright/branding-off`: успешна; проверено отсутствие официальных изображений на публичной странице.
- Playwright/Edge: 6 комплексных сценариев, сохранение и версии Workspace, роли, фото, геолокация на синтетических координатах, полигон, комиссия и PDF.
- Дополнительная браузерная проверка: 20 модулей, поиск Kaspersky показывает честный статус, ссылка Workspace ведёт на `/app/workspace`, Escape закрывает меню, ширина 390 пикселей не создаёт переполнения.

Снимки: `frontend/test-results/directive-hero.png`, `directive-menu-mobile.png`, `branding-disabled.png`. Сохраняется ранее документированное предупреждение TestClient; тесты проходят.

Цифровой двойник, граф расследования, Integration Hub и адаптеры, почтовый анализатор, Aegis AI, задачи, визуальный конструктор правил и полноценные учебные курсы пока не завершены. ## Как продолжить

Открыть http://127.0.0.1:8000/ ; панель http://127.0.0.1:8000/app ; Workspace http://127.0.0.1:8000/app/workspace . Для повторного запуска — `Запустить.bat` при работающем Docker Desktop либо команда Compose из INSTALL_WINDOWS.

Следующий этап: граф по фактическим связанным событиям и документы внутри расследования; затем модель тестовой инфраструктуры и валидируемый импорт JSON/CSV с журналом. Статусы сверять с FEATURE_STATUS, сроки — с ROADMAP_2026.
