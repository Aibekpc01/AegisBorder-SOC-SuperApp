## Сервисы и подключения

Работают `app`, `db`, `proxy` проекта Compose `aegisborder_soc_v02`.
Приложение и БД имеют статус healthy; HTTPS отвечает 200 с валидным сертификатом.
Docker включён в автозапуск, у всех трёх сервисов `restart: unless-stopped`.
PostgreSQL не опубликован в Интернет, приложение слушает только loopback VM;
внешний доступ проходит через HTTPS-прокси.

Проверено, что IP берётся из заголовка доверенного Caddy `10.88.7.10/32`,
а не подменяется адресом контейнера. Карточка нового подключения обновляется
после первого успешного heartbeat. Закрытие последней вкладки отправляет
отключение; повторное открытие возвращает онлайн. При потере сети сохраняется
таймаут 75 секунд; списки опрашиваются каждые 10 секунд.

Марка/модель доступны в пределах сведений браузера. Город определяется по
разрешённым координатам и локальному справочнику либо по справочнику сетей
администратора; точный город по IP не обещается. Общие IP видит администратор,
остальные пользователи видят свои устройства.

Реальные адаптеры CRM и Qainar.knb не включались: по уточнению владельца они
показаны как будущие этапы. Синтетические киберсценарии остаются обозначенными
учебными примерами. Рабочие подключения браузеров являются реальными.

## Откат

Предыдущее обновление интерфейса сохранено как
`aegisborder-supperapp:rollback-20261015-r3.1` (версия r3).
Исходный образ до всей публикации —
`aegisborder-supperapp:rollback-20261015-r3` (прежняя версия SuperApp r2).

Для возврата к r3 из рабочего каталога восстановить только Compose и контейнер:

```bash
sudo cp -p /home/ubuntu/aegisborder-backups/supperapp-20261015-r3/compose.pre-refresh.yaml compose.oracle.yaml
sudo docker compose -p aegisborder_soc_v02 -f compose.yaml -f compose.oracle.yaml up -d --no-build --no-deps --wait app
```

Для возврата к r2 использовать `compose.oracle.yaml` из той же резервной копии.
Обычный откат приложения не требует восстановления базы поверх новых данных.
Не удалять том PostgreSQL и не выполнять `down -v`. Перед будущей пересборкой
сверить исходники с выбранной версией образа.
