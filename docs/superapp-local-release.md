# Учебный релиз SuperApp — 15 октября 2026

Для просмотра без IT-подготовки используйте «Простой режим» и кнопку «Показать систему по шагам» на главной. Каждый раздел содержит пояснение результата и три шага. Кнопка «Понятная справка» объясняет термины. Подготовка учебных записей и тренировок доступна через обычные поля; знание JSON не требуется. Инструкция для показа: [first-visit.md](first-visit.md).

Новые разделы доступны после входа через боковую панель и меню платформы:

| Адрес | Возможность |

| /app/assistant | Черновик расследования по сохранённому инциденту |
| /app/mail | Локальная проверка текста учебного письма и история |
| /app/m365 | Мониторинг импортированных учебных событий Microsoft 365 |

| /app/integrations | Проверка и импорт нормализованных событий JSON/CSV |
| /app/rule-builder | Создание правила подсчёта событий по типу и окну |
| /app/academy | 12 учебников, 36 глав, примеры, скачивание и проверка знаний |
| /app/team | Сотрудники проекта и сохраняемый чат по трём темам |

Граф доказательств находится в карточке инцидента. Нажатие узла фильтрует события; связанные документы открываются непосредственно в редакторе. Адрес `/app/workspace?incident=ID` показывает связанные материалы и подставляет инцидент при создании документа. `/app/workspace?document=ID` открывает сохранённый документ и поддерживает обновление страницы.

## Импорт и сценарии

В центре интеграций нажмите «Заполнить учебный пример», затем «Проверить файл». После успешной проверки выполните импорт. Формат JSON — массив событий, CSV — заголовки external_id,time,device,account,source,type,detail,features. Время включает часовой пояс; features содержит JSON-объект. Сервер валидирует весь пакет до записи. Ошибка или конфликт чужого external_id отменяет весь импорт. Повтор своего external_id пропускается. Лимиты: 200 событий, 200 КБ.

Импорт общих событий доступен аналитику и администратору. Demo-пользователь проверяет формат и использует личные сценарии. В конструкторе сохраните название и JSON-последовательность до 100 событий с интервалами не более 24 часов. При запуске создаются новые external_id и отдельный demo-сеанс; интервалы сохраняются, события обрабатывает прежний Detection Engine. Сброс этого сеанса не удаляет шаблон или задачу: связь задачи с удалённым инцидентом снимается с повышением ревизии и аудитом.

## Задачи и роли

Наблюдатель читает доступные задачи, но не меняет их; курсы и собственные результаты обучения ему доступны. Demo видит только свои задачи и журналы. Личная задача назначается только владельцу. Общая задача не назначается demo-пользователю.

Переходы: Новая → В работе → На проверке → Завершена. Допустимы возврат на предыдущую проверку и повторное открытие завершённой задачи. Владелец, ответственный или администратор меняет задачу; завершение подтверждает постановщик или администратор. Устаревшая ревизия возвращает 409; автоматического перезаписывания нет.

## Границы текущего релиза

Языковая модель, реальные почтовые серверы, Microsoft Graph, Kaspersky и DLP не подключены. Анализ письма — объяснимые эвристики, а не гарантия безопасности. Двойник показывает связи по событиям и не измеряет сетевую топологию. Академия выдаёт учебный результат, а не профессиональную сертификацию.

Новые модули вынесены в отдельный лениво загружаемый компонент и отдельный API-router с типизированными входами. Прежний Command Center ещё требует дальнейшего разделения и замены всех Row/any на строгие DTO. Это архитектурная задача, а не выполненный пункт релиза. Независимый обзор, длительная нагрузка и Windows на другом компьютере остаются открытыми.
