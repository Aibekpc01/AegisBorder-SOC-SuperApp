# Безопасность и ограничения

Пароли: Argon2. JWT: HS256, issuer, обязательные exp/sub/jti/iat; срок два часа. Сеанс хранится в БД, выход отзывает jti. Cookie HttpOnly, SameSite=Strict; Secure автоматически включается при HTTPS. HTTP допускается для loopback-демонстрации.

Роли: администратор управляет пользователями, настройками и правилами; аналитик расследует и создаёт отчёты; наблюдатель читает; demo запускает сценарии только в собственном сеансе. Проверки прав выполняются API. Демонстрационные записи фильтруются по владельцу; другой участник не может сбросить чужой сеанс. Реальные устройства не управляются ни одной ролью.

Вход ограничен десятью попытками в минуту для пары IP/логин и тридцатью с одного IP. Изменяющие запросы API ограничены 120 в минуту с одного IP. Лимитер работает в памяти одного процесса; до нескольких экземпляров приложения требуется общий лимитер. Неудачный вход известной учётной записи фиксируется в аудите. Для неизвестных имён отдельный журнал безопасности пока не реализован.

Изменяющие запросы проверяют Origin при его наличии; cookie SameSite ограничивает межсайтовые запросы. WebSocket проверяет Origin и JWT. HTML не вставляется из пользовательских строк; PDF экранирует текст. Установлены nosniff, запрет iframe, no-store для API.

HMAC-аудит использует транзакционную блокировку в PostgreSQL. Ключ AUDIT_KEY не короче 32 символов. JWT-ключ выводится из него с отдельной меткой. Ротация ключа требует отдельной процедуры: замена нарушит проверку прежней цепочки и отзовёт JWT. Цепочка не заменяет внешний якорь доверия и не обнаруживает удаление её хвоста без сохранённого контрольного значения.

.env исключён из Git и Docker-контекста. Не передавайте резервные копии и локальные настройки третьим лицам. Весь используемый контент учебный; ведомственная символика и официальное одобрение не подразумеваются.

Перед размещением в сети: TLS, отдельные ключи JWT/аудита и их ротация, ограниченный пользователь PostgreSQL, внешнее закрепление хешей аудита, контроль резервного восстановления, общий rate limiter, проверка зависимостей и независимая оценка безопасности. Текущая версия не аттестована для служебных данных.

Новые профили и фото доступны владельцу и администратору. Фото декодируется и перекодируется в PNG без исходных метаданных, хранится в БД и не выдаётся анонимно. Входы фиксируют наблюдаемый сервером IP; координаты передаются только по кнопке с разрешением браузера и явно обозначаются как не проверенные независимо. Сетевая политика блокирует запрещённые диапазоны и известные по локальному справочнику анонимайзеры; неизвестные VPN не объявляются безопасными.
