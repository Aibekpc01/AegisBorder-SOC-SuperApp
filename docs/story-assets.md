# Иллюстрации истории защиты

Созданы встроенным `imagegen`, без API-ключа проекта. Оба персонажа вымышленные. Нашивка на сгенерированном портрете стилизована; рядом в интерфейсе используется существующий файл эмблемы КНБ. Исходные изображения сохранены в проекте:

- `frontend/src/assets/story/hacker.png`
- `frontend/src/assets/story/operator.png`

Промпт злоумышленника:

> Create a standalone cinematic photorealistic portrait for a cybersecurity educational website. Fictional anonymous hacker in a dark hoodie seated at a laptop, intriguing calm character, face in partial shadow, natural textures. Dark navy room, amber rim lighting and subtle laptop glow. Vertical waist-up composition, centered subject, premium film still, restrained realistic aesthetics. No text, no logos, no watermark, no readable code, no weapons, no extra people. Save as a project asset; output a portrait image.

Промпт оператора:

> Use case illustration-story. Create a premium cinematic photorealistic vertical waist-up portrait of a fictional Kazakh SOC cybersecurity operator in a modern security operations room, navy professional polo uniform, headset, calm capable friendly expression, seated by a keyboard with defocused blue screens behind. Natural realistic human skin and fabric, teal rim lighting, restrained deep navy cinematic color grading. On the chest a tasteful Kazakhstan national security committee emblem patch (gold sun and star, blue/gold shield, KNB RK) and a readable small white label 'SOC OPERATOR'. This is a fictional educational character, not a portrait of an actual official. Centered subject with shoulder/chest patch clearly visible. No weapons, no extra people, no watermark, no large headlines, no readable screen code. Output one standalone portrait image.
