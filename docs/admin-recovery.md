# Восстановление доступа администратора

Процедура доступна оператору компьютера, имеющему доступ к базе и `.env`. HTTP-маршрута обхода авторизации нет. Существующая учётная запись должна иметь роль admin; новая запись не создаётся и роль другого пользователя не повышается.

Для локального запуска остановите приложение, сделайте копию SQLite-базы и сохраните `.env` отдельно. Выполните из корня проекта:

```powershell
.venv/Scripts/python.exe scripts/recover_admin.py --username admin
```

Введите имя пользователя для подтверждения и новый пароль дважды. Пароль не выводится и не передаётся через аргументы командной строки. После восстановления все предыдущие сеансы этого администратора отозваны, операция добавлена в HMAC-аудит. Запустите приложение и войдите с новым паролем.

Для Docker сначала сохраните дамп PostgreSQL и остановите приложение командой `docker compose stop app`. В новом образе скрипт доступен в `/code/scripts`:

```powershell
docker compose run --rm --no-deps app python scripts/recover_admin.py --username admin
docker compose up -d app
```

Сохраняйте исходный AUDIT_KEY: его замена нарушает проверку исторического аудита и документов. Изменение ADMIN_PASSWORD в `.env` не меняет пароль существующей учётной записи.
