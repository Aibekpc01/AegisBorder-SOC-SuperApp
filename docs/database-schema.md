# Схема базы данных

Новые таблицы имеют префикс `cc_`; таблицы v0.2 сохранены. Миграции Alembic используют отдельную таблицу `cc_alembic_version`.

| Таблица | Назначение |
|---|---|
| cc_users | Учётные записи, Argon2-хеш, роль, активность |
| cc_roles | Справочник четырёх ролей, внешний ключ пользователя |
| cc_auth_sessions | JWT jti, срок, отзыв |
| cc_assets | Учебные устройства |
| cc_security_events | Нормализованные события и признаки |
| cc_detection_rules | Настраиваемые правила |
| cc_alerts | Параметры срабатывания |
| cc_incidents | Риск, статус, объяснение, ответственный |
| cc_incident_events | Связь событий и инцидентов |
| cc_incident_comments | Комментарии |
| cc_incident_history | История смены состояния |
| cc_investigations | Проверки и вывод оператора |
| cc_audit_logs | HMAC-цепочка действий |
| cc_demo_sessions | Владелец и прогресс проверки |
| cc_scenario_runs | Запуски генератора |
| cc_reports | Неизменяемый через API снимок отчёта |
| cc_model_versions | Параметры и результаты ML-анализа |
| cc_settings | Настройки учебного центра |
| cc_user_profiles | Личные поля и защищённое PNG-фото в БД |
| cc_login_records | IP, источник, время, результат входа и добровольно переданные координаты |
| cc_workspace_documents | Документы, проверенное JSON-содержимое, ответственный, инцидент, статус и версия |
| cc_document_versions | Снимки изменений с HMAC и уникальностью document_id/revision |
| cc_document_comments | Сохраняемые комментарии и заметки к материалам |

Индексы: время, устройство, учётная запись, тип, владелец, демонстрационный сеанс, статус. Внешние ключи связывают пользователей, сеансы, запуски, события и расследования. Уникальны имя пользователя, имя устройства, внешний ID события, пара инцидент/событие и расследование инцидента.

SQLite поддерживает облегчённый режим. Гарантии параллельной обработки следует проверять на PostgreSQL; SQLite не заменяет серверную БД при многопользовательской эксплуатации.

Перед обновлением: сохранить `pg_dump -Fc`, проверить архив через pg_restore --list. Применение: `alembic upgrade head`. Автоматический downgrade, удаляющий данные, отключён.
