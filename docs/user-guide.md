# Инструкция новому сотруднику

Войдите по выданной учётной записи. Главная панель показывает сохранённые события и инциденты. Если данных нет, откройте «Режим комиссии» и выполните учебную проверку.

Учебный полигон находится в «Учебных сценариях». Выберите категорию, найдите ситуацию поиском и нажмите её карточку. Справа появятся описание, цель тренировки и четыре доступных для нажатия этапа. «Как это работает» открывает наглядную интерактивную схему.

После «Запустить сценарий» полигон переходит к результатам. Нажмите на строку хронологии для просмотра подробностей события. «Начать расследование» открывает реальный инцидент. «Повторить тренировку» создаёт новый запуск; правила могут объединить доказательства в существующий инцидент. Запуски полигона выполняются в собственном учебном сеансе.

В «Справке и обучении» вместо списка шагов показана картинка-схема: шесть карточек, связанные маршрутом. Каждая карточка нажимается и поддерживает клавиатуру; под схемой появляются объяснение и переход в нужный раздел. На небольшом экране картинку можно прокрутить горизонтально.

«Мониторинг событий»: поиск по описанию, устройству или учётной записи; фильтр уровня; кнопки перехода между страницами. «Центр инцидентов»: поиск и фильтр статуса, открытие карточки стрелкой справа. «Расследования» — рабочий список тех же инцидентов.

В карточке: объяснение риска, связанные события, смена статуса по этапам, назначение себя, чек-лист, вывод, комментарии и история. Сохраните вывод отдельной кнопкой перед формированием PDF. Наблюдатель не меняет данные.

«Умный анализ» показывает правила, их пороги и окна. Администратор меняет параметры и запускает повторный анализ. «Обнаружение аномалий» отдельно запускает модель Isolation Forest и показывает признаки, версию и оценки. Аномалия не доказывает наличие атаки.

«Контроль компьютеров» содержит учебный инвентарь и переход к событиям устройства. «Пользователи и роли» позволяет администратору создавать и отключать учётные записи. «История действий» показывает аудит и проверку HMAC.

В верхней панели можно переключить простой и технический режим. Для выхода используйте значок справа: сеанс будет отозван на сервере. Сообщения об ошибках показываются уведомлением; при истечении сеанса войдите повторно.

Под рабочими блоками теперь есть описание назначения и раскрываемая инструкция «Как пользоваться этим блоком». Карточки показателей открывают соответствующий раздел. Нажатие строки события открывает его подробности.

В «Пользователях и ролях» доступны поиск, фильтр роли, показ отключённых записей и карточки с фото. Откройте карточку для личных данных, роли и истории IP. Свой профиль открывается аватаром в верхней панели. Подробнее — [профили и сетевой доступ](profiles-and-network-access.md).

## Новые возможности SuperApp

Адрес `/` открывает знакомство с платформой. Кнопка «Открыть рабочую панель» ведёт в `/app`, «Запустить демонстрацию» — в защищённый режим комиссии. Для запуска ситуаций нужно войти в свою учебную учётную запись. Лендинг показывает обозначенный пример, не результат запуска.

В верхней панели появились поиск по событиям/инцидентам (также Ctrl+K), список незакрытых инцидентов и переключатель темы. Материалы расследования редактируются и сохраняются в разделе «Документы и рабочее пространство»: [пошаговая инструкция](workspace.md).
