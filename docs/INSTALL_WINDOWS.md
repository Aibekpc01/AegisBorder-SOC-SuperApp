# Запуск AegisBorder SuperApp на Windows

Основная подробная инструкция: [installation-windows.md](installation-windows.md). Версии и реально проверенные ограничения указаны там.

При запущенном Docker Desktop выполните в папке проекта:

```powershell
docker compose up -d --build --wait --wait-timeout 240
docker compose ps
```

Главная: http://127.0.0.1:8000/ ; панель: http://127.0.0.1:8000/app ; документы: http://127.0.0.1:8000/app/workspace . Вход по действующей учётной записи. Для повторного запуска можно использовать `Запустить.bat`.

Чтобы выключить эмблемы в публичной части, задайте `VITE_PUBLIC_OFFICIAL_EMBLEMS=false` в локальном `.env` и пересоберите приложение. Это открытый параметр оформления, не секрет. В локальной Vite-сборке задаётся одноимённой переменной окружения. На лендинге используется знак AegisBorder; символика на защищённом входе/в рабочей области сохраняется. Значок вкладки — собственный знак AegisBorder.

Не используйте `docker compose down -v`: это удаляет том. Сохраняйте `.env` и AUDIT_KEY при переносе базы. Windows 8/8.1 не проверены. Отдельная чистая Windows 10 пока не проверена; текущие успешные прогоны не заменяют этот этап приёмки.
