## 3. Сквозные тесты Playwright

Тест `frontend/e2e/command.spec.ts` создаёт учётную запись через `docker compose exec` в рабочей базе. Чтобы не трогать рабочие данные, тот же набор запускался против двух изолированных серверов с отдельными SQLite-базами: исходная версия (`0628286`) и новая. Сами проверки не менялись, заменён только способ создания тестовой учётной записи.

Результат одинаковый: 3 прошли, 11 упали **в одних и тех же строках**. Причины — тест отстал от кода ещё до редизайна:

## 6. Как повторить

```powershell
.venv\Scripts\python.exe -m pytest -q
cd frontend
npx tsc --noEmit; npx eslint .; npx vitest run
npx vite build
node scripts/review-perf.mjs http://127.0.0.1:8000 <пароль>
```

Примечание: в Git Bash на этой машине Vitest падает из-за окружения оболочки; в PowerShell и `cmd` все 32 теста проходят.
