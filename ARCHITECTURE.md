# Архитектура AegisBorder Supperapp

## 1. Общая схема

```
┌──────────────────────── Браузер ────────────────────────┐
│ React 19 SPA (Vite)                                     │
│  /            → Landing (ленивый чанк)                  │
│  /app/*       → CommandCenter (ленивый чанк, 29 разделов)│
│  TanStack Query ─ кэш запросов   WebSocket ─ живая лента │
└───────────────┬─────────────────────────────┬───────────┘
                │ HTTPS, cookie aegis_session │ wss /api/v1/ws
┌───────────────▼─────────────────────────────▼───────────┐
│ FastAPI (app/command/api.py)                             │
│  middleware guard: лимиты записи · проверка Origin ·     │
│                    заголовки безопасности (headers.py)    │
│  StaticCompression: gzip статики (не API)                │
│  роутеры: profiles · workspace · superapp · connectors · │
│           presence · news · governance · dlp             │
│  домен:  detection (правила) · analytics (аномалии) ·    │
│          scenarios (синтетика) · reports (PDF) · rbac     │
└───────────────┬─────────────────────────────────────────┘
                │ SQLAlchemy 2
┌───────────────▼──────────────┐
│ PostgreSQL 16 (SQLite в тестах)│  миграции Alembic 001–010
└──────────────────────────────┘
```

Развёртывание: `compose.yaml` (локально), `compose.oracle.yaml` (Oracle Cloud + Caddy с HTTPS), `compose.public-demo.yaml` (публичная демонстрация), `render.yaml`. Образ собирается в два этапа: Node собирает интерфейс, Python-образ получает только готовые файлы (`Dockerfile`).

## 2. Поток данных: от события до отчёта

1. **Приём.** Событие приходит из учебного сценария (`scenarios.generate`), через API-приёмник интеграций (`connectors`) или от агента устройства (`dlp`, `presence`).
2. **Нормализация и сохранение.** `detection.ingest` проверяет поля, сохраняет `Event`.
3. **Обнаружение.** `detection.analyze` применяет детерминированные правила с временными окнами и порогами. Причина срабатывания сохраняется — оператор видит, *почему* система насторожилась.
4. **Инцидент.** Сработавшее правило создаёт или дополняет `Incident`; связи событий хранятся в `IncidentEvent`.
5. **Расследование.** Статусы, ответственный, комментарии, граф связей, документ в Workspace с версиями.
6. **Отчёт.** `reports.pdf` формирует PDF с кириллицей (ReportLab + DejaVu).
7. **Журнал.** Каждое действие пишет запись `Audit`, подписанную HMAC-SHA256 вместе с подписью предыдущей записи. `/api/v1/audit/verify` проверяет всю цепочку.

Аномалии (`analytics.run_model`) работают отдельно: scikit-learn на синтетических данных, версии модели хранятся в `ModelVersion`.

## 3. Безопасность

| Механизм | Где | Решение |
|---|---|---|
| Пароли | `security.py` | Argon2 (`argon2-cffi`) |
| Сеанс | `api.py: login` | JWT в cookie `HttpOnly`, `SameSite=Strict`, `Secure` при HTTPS, 2 часа; отзыв сеансов на сервере |
| Перебор паролей | `api.py: login` | ≤ 10 попыток на логин и ≤ 30 на IP в минуту |
| CSRF | `api.py: guard` | `SameSite=Strict` + проверка заголовка `Origin` для всех изменяющих запросов |
| Лимит записи | `api.py: guard` | 120 изменяющих запросов в минуту на адрес (у агентов DLP — своя квота) |
| Роли | `rbac.py` | Иерархия рангов; сервер запрещает действия над пользователем с рангом выше своего и над самим собой |
| Заголовки | `headers.py` | CSP только `'self'`, `frame-ancestors 'none'`, Permissions-Policy (только геолокация), HSTS при HTTPS, `nosniff`, `Referrer-Policy` |
| Кэш | `headers.py` | API — `no-store`; `/assets/*` (хеш в имени) — `immutable` на год; HTML — `no-cache` |
| Журнал | `security.audit`, `/audit/verify` | Цепочка HMAC: изменение старой записи обнаруживается |
| Секреты | `.env` | Не попадают в репозиторий и в клиентский код; клиент получает только `VITE_PUBLIC_OFFICIAL_EMBLEMS` |
| Закрытый контур | весь интерфейс | Нет внешних CDN, шрифтов, счётчиков. Исключение: страница Swagger `/docs` (FastAPI), для неё CSP не применяется |

Почему gzip не включён для `/api`: ответы API содержат пользовательские данные; сжатие рядом с секретами открывает атаки класса BREACH. Сжимаются только статика и HTML.

## 4. Клиент

```
frontend/src/
  main.tsx               вход: тема, провайдеры, ленивые страницы, предзагрузка чанка
  api.ts                 единственная точка HTTP: префикс /api/v1, ошибки, события 401/428
  command-center.tsx     оболочка /app: вход, навигация, шапка, разделы
  components/
    landing.tsx          публичная главная
    landing/             сцена «Цифровой рубеж» и консоль обработки сигнала
    ui/                  примитивы (Button на CVA, Dialog на Radix)
    …                    экраны разделов
  lib/                   чистые функции (маршруты, утилиты) — покрыты Vitest
  styles/
    tokens.css           дизайн-токены (единый источник)
    system.css           общий слой компонентов приложения
    landing.css          стили главной (только в её чанке)
```

**Почему SVG вместо Three.js на главной.** Сцена весит несколько килобайт, рисуется сразу, не требует WebGL, одинаково работает в закрытой сети и на слабом компьютере комиссии. Движение отключается при `prefers-reduced-motion`.

**Почему стили слоями.** Исторически в проекте 12 глобальных CSS-файлов. Переписать их сразу — высокий риск регрессий перед показом. Поэтому введены токены, к которым привязаны старые переменные, и последний слой `system.css`, задающий общий вид. Порядок дальнейшей миграции описан в `DESIGN_SYSTEM.md`.

**Ленивая загрузка.** Главная и приложение — разные чанки. Код нужного чанка начинает загружаться одновременно с проверкой готовности сервера (`EntryCheck`), а не после неё. Помощник по сайту загружается отдельно и не задерживает первый экран.

## 5. Данные

Миграции `migrations/versions/001…010`. 29 таблиц с префиксом `cc_`, основные: `cc_users`, `cc_roles`, `cc_auth_sessions`, `cc_login_records`, `cc_security_events`, `cc_detection_rules`, `cc_alerts`, `cc_incidents`, `cc_incident_events`, `cc_incident_history`, `cc_investigations`, `cc_reports`, `cc_audit_logs`, `cc_workspace_documents` + `cc_document_versions`, `cc_assets`, `cc_connectors`, `cc_dlp_devices`, `cc_settings`. Схема БД в этой итерации **не менялась**.
