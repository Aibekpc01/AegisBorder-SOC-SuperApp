# frontend/src/lib/

Клиентские справочники, маршруты и общие функции. dlp-proof.ts связывает браузер с локальной службой.

Общая карта: [SOURCE_GUIDE.md](../../../SOURCE_GUIDE.md).

Файлы непосредственно в этой папке:

- [access.ts](access.ts) — Содержит клиентские проверки доступности функций по роли. Окончательное разрешение выдаёт сервер.
- [brand.ts](brand.ts) — Хранит название, слоган и общие текстовые константы бренда.
- [defense-story.test.ts](defense-story.test.ts) — Проверяет подсистему defense story. Содержит проверки ожидаемого поведения, а не код рабочего сервера.
- [defense-story.ts](defense-story.ts) — Показывает учебную историю атаки с хакером, оператором и переключением модулей. Сама история не выполняет действия на устройствах.
- [dlp-proof.ts](dlp-proof.ts) — Получает одноразовый код у сервера и передаёт его локальной службе на 127.0.0.1:17645 для подтверждения текущего ПК.
- [explainers.ts](explainers.ts) — Хранит краткие объяснения понятий и функций интерфейса.
- [learning-examples.test.ts](learning-examples.test.ts) — Проверяет подсистему learning examples. Содержит проверки ожидаемого поведения, а не код рабочего сервера.
- [learning-examples.ts](learning-examples.ts) — Хранит примеры для объяснения рабочих ситуаций пользователю.
- [local-guide.test.ts](local-guide.test.ts) — Проверяет подсистему local guide. Содержит проверки ожидаемого поведения, а не код рабочего сервера.
- [local-guide.ts](local-guide.ts) — Содержит локальные ответы и справочные сведения для помощника.
- [modules.ts](modules.ts) — Описывает каталог модулей, их подписи и назначение.
- [routes.test.ts](routes.test.ts) — Проверяет подсистему routes. Содержит проверки ожидаемого поведения, а не код рабочего сервера.
- [routes.ts](routes.ts) — Хранит правила и вспомогательные функции маршрутизации между разделами.
- [training-events.test.ts](training-events.test.ts) — Проверяет подсистему training events. Содержит проверки ожидаемого поведения, а не код рабочего сервера.
- [training-events.ts](training-events.ts) — Подготавливает события для учебных заданий.
- [utils.test.ts](utils.test.ts) — Проверяет подсистему utils. Содержит проверки ожидаемого поведения, а не код рабочего сервера.
- [utils.ts](utils.ts) — Содержит общие вспомогательные функции интерфейса, включая сборку CSS-классов.
