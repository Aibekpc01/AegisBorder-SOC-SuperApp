# frontend/src/

Исходники интерфейса. main.tsx запускает приложение, command-center.tsx собирает рабочую оболочку, api.ts обращается к серверу.

Общая карта: [SOURCE_GUIDE.md](../../SOURCE_GUIDE.md).

Файлы непосредственно в этой папке:

- [api.test.ts](api.test.ts) — Проверяет подсистему api. Содержит проверки ожидаемого поведения, а не код рабочего сервера.
- [api.ts](api.ts) — Единая точка HTTP-запросов к /api/v1. Передаёт cookie сеанса, разбирает JSON и сообщает интерфейсу об истечении сеанса и требовании DLP.
- [assets/](assets/FOLDER_GUIDE.md) — Изображения, эмблемы и другие ресурсы, которые Vite включает в сборку.
- [beginner.css](beginner.css) — Стили beginner: задают внешний вид соответствующих классов и адаптацию экрана. Применяются через импорты интерфейса.
- [command-center.tsx](command-center.tsx) — Собирает защищённую оболочку, вход, навигацию и рабочие экраны. Учитывает состояние сеанса и требования DLP.
- [components/](components/FOLDER_GUIDE.md) — Компоненты страниц и общие элементы интерфейса. DLP сосредоточен в dlp-workspace.tsx и dlp-required.tsx.
