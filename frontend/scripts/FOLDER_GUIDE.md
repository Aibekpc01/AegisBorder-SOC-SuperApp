# frontend/scripts/

Служебные браузерные проверки отдельных выпусков. Сценарии могут требовать работающий сервер и тестовые учётные данные.

Общая карта: [SOURCE_GUIDE.md](../../SOURCE_GUIDE.md).

- [presence-check.mjs](presence-check.mjs) — Проверяет подсистему presence. Содержит проверки ожидаемого поведения, а не код рабочего сервера.
