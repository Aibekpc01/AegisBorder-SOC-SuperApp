Aegis DLP 2.0 — Windows 10/11 x64

Python не требуется. Используется штатный .NET Framework 4.8 Windows.
Распакуйте архив и запустите AegisDLP.exe. Установка требует подтверждения UAC
администратором Windows и задаёт отдельный локальный пароль.

Устанавливается видимая служба Aegis DLP (LocalSystem) и значок в трее при входе.
Служба работает до входа пользователя и при выходе из Windows, в том числе без сети.
Закрытие значка не останавливает службу. Локальное окно открывается по паролю.

Все политики, статистика и запросы проверок — в разделе Aegis DLP на сайте.
После установки нажмите на сайте «Агент установлен — подтвердить этот ПК».
Разрешите браузеру соединение с локальной службой, если появится запрос.
Подтверждается именно текущий сеанс и локальная служба на этом компьютере.

Кэш подписанной политики, ключ, резервная копия USB-политики и очередь событий
защищены DPAPI и ACL каталога ProgramData\AegisDLP\Private (SYSTEM/Administrators).
При отсутствии сети политика сохраняется, события отправляются при восстановлении.

Обычный сотрудник не может остановить/удалить службу или изменить её файлы.
Администратор Windows сохраняет контроль. Поддерживаемое удаление — Windows
«Приложения», Aegis DLP, с правами администратора и локальным паролем; прежняя
USB-политика восстанавливается. Нет скрытой установки или запрета действий администратора.

Запрет съёмных дисков не равен запрету любого USB: мыши, клавиатуры, MTP и другие
классы не блокируются. Доменная политика может иметь приоритет. Проверяйте ограничения
на тестовом ПК перед массовым включением. Антивирусный движок — Windows Defender.

Сборка пока без цифровой подписи издателя. SHA-256 доступен через /api/v1/dlp/native-build.
Архив содержит ключ активации: не публикуйте его и удалите после установки.
