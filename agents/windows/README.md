# Aegis DLP — автономный Windows-пилот

Продукт называется Aegis DLP. Антивирусный движок — установленный Defender.
Microsoft Purview/DLP не используется. Это исходники пилота, не готовый установщик.

## Полностью автономный запуск

Нужен Python с Tkinter и зависимостями. Заранее подготовьте Python и пакеты
на подключённом компьютере той же архитектуры и версии Python:

```powershell
python -m pip download -r requirements.txt -d wheels
# Затем на отключённом компьютере:
python -m pip install --no-index --find-links wheels -r requirements.txt
python endpoint_agent.py init
python console.py
python endpoint_agent.py run
```

Без --endpoint сервер не требуется. Пароль задаёте сами: минимум 12 символов,
хранение Argon2-хеша. Общего секретного кода нет. Пять неудачных попыток блокируют
вход на пять минут, включая перезапуск. Консоль закрывается через минуту после входа.
Команды change-password, show-settings, quick-scan, usb-block и usb-restore требуют
пароль. Фоновый сбор не требует входа при каждом цикле.

Данные: `%LOCALAPPDATA%\AegisBorderEndpoint`. Защитите каталог ACL Windows.
Пароль приложения не ограничивает администратора Windows. Очередь SQLite пока
не зашифрована. Службы и автозапуска пока нет: run должен оставаться запущенным.

## Запрет съёмных дисков

В повышенной консоли администратора с тем же каталогом данных:

```powershell
python endpoint_agent.py usb-block
python endpoint_agent.py usb-restore
```

Сохраняются прежние значения, затем запрещаются чтение, запись и выполнение
для класса съёмных дисков. Мыши и клавиатуры не затрагиваются. Это не запрет всех
USB: телефоны MTP и другие классы требуют отдельных политик. Исключений по серийным
номерам пока нет. Может потребоваться переподключение или перезапуск.
Успех команды означает запись политики, а не проверку её фактического применения.

usb-restore восстанавливает прежние значения. Резервная копия usb-backup.json
сохраняется при частичной ошибке и не перезаписывается повторным запретом.
Доменная/MDM-политика может перезаписать локальную настройку.
На рабочем компьютере ограничения автоматически не запускались.

## Антивирус и синхронизация

Defender проверяет по локальным базам без сети; актуализация баз и облачная проверка
требуют доставки обновлений. quick-scan явно запускает быструю проверку.
Отсутствие обнаружений не гарантирует отсутствие угроз.

Состояние и обнаружения сохраняются в SQLite, доставка повторяется каждые 60 секунд.
Нет передачи содержимого документов или клавиатурного ввода. Лимит — 10 000 ожидающих
событий. При заполнении сбор сообщает ошибку, старые события не удаляет. ID доставленных
событий сохраняются для дедупликации. Контролируйте размер базы при длительной изоляции.

Для связи создайте generic-приёмник Supperapp и передайте его отдельный ключ
через AEGIS_CONNECTOR_TOKEN. Не используйте пароль администратора сайта.

```powershell
python endpoint_agent.py init --endpoint https://YOUR-HOST/api/v1/integrations/receivers/ID/events
python endpoint_agent.py run
```

Повторный init требует прежний пароль и задаёт новый. Очередь сохраняется.
Для автоматических инцидентов настройте правило malware_detected с порогом 1.

Для промышленной версии нужны: подписанный установщик, служба, ACL/DPAPI,
защищённая очередь, подписанные политики и Windows-пилот. Контроль содержимого
документов и предотвращение утечек пока не реализованы.

[Политики Windows](https://learn.microsoft.com/en-us/windows/client-management/mdm/policy-csp-admx-removablestorage).
