# app/command/

Серверные маршруты, модели БД, авторизация, обработка событий и DLP. Начните с api.py, models.py и security.py.

Общая карта: [SOURCE_GUIDE.md](../../SOURCE_GUIDE.md).

Файлы непосредственно в этой папке:

- [__init__.py](__init__.py) — Обозначает Python-пакет для импорта соседних модулей.
- [access.py](access.py) — Применяет локальную сетевую политику: доверенные и запрещённые подсети, сведения о подключении и ограничения доступа.
- [analytics.py](analytics.py) — Выполняет дополнительную модельную оценку событий и сохраняет результаты анализа.
- [api.py](api.py) — Собирает FastAPI-приложение: запуск, вход, события, инциденты, аудит и подключение дополнительных маршрутов.
- [avatars.py](avatars.py) — Обрабатывает изображения профиля и подготовку аватаров для интерфейса.
- [connectors.py](connectors.py) — Подключает внешние источники событий и обрабатывает настройки интеграций. Реальная работа зависит от заданных подключений.
- [curriculum.py](curriculum.py) — Хранит учебные материалы и задания для знакомства с разделами и сценариями безопасности.
- [db.py](db.py) — Создаёт подключение SQLAlchemy и выдаёт отдельную сессию БД каждому запросу. Локально используется SQLite, на сервере — PostgreSQL.
- [detection.py](detection.py) — Сопоставляет события с правилами, временными окнами и порогами; создаёт предупреждения и связывает доказательства с инцидентами.
- [dlp.py](dlp.py) — Реализует API Aegis DLP: выдачу установочного ZIP, регистрацию устройств, heartbeat, события, назначения и политики.
- [dlp_gate.py](dlp_gate.py) — Решает, можно ли открыть рабочие функции: проверяет назначение DLP, связь с браузерным сеансом и свежесть состояния службы.
- [governance.py](governance.py) — Управляет административными настройками, ролями и организационными ограничениями приложения.
- [hosting.py](hosting.py) — Нормализует параметры размещения и строку подключения к базе для разных окружений.
- [location.py](location.py) — Сопоставляет доступные координаты и локальные справочники с географическими сведениями.
- [models.py](models.py) — Описывает таблицы основного контура: пользователи, сеансы, события, правила, инциденты и аудит. Изменения схемы оформляются миграциями.
- [news.py](news.py) — Получает и подготавливает новости для отображения в приложении.
- [presence.py](presence.py) — Обрабатывает heartbeat браузеров, присутствие пользователей и сведения об устройствах и подключениях.
- [profile_routes.py](profile_routes.py) — Предоставляет HTTP-маршруты для чтения и изменения пользовательских профилей.
- [profiles.py](profiles.py) — Содержит правила работы с профилями, их полями и доступом к персональным сведениям.
- [rbac.py](rbac.py) — Определяет базовые и пользовательские роли, полномочия руководителей и доступ к функциям DLP.
- [recovery.py](recovery.py) — Обслуживает восстановление доступа и проверку условий безопасного изменения учётных данных.
- [reports.py](reports.py) — Формирует PDF-отчёты с данными расследования; отвечает за оформление и шрифты документа.
- [scenarios.py](scenarios.py) — Хранит учебные сценарии и генерирует события для демонстрации детектирования. Это отдельный источник учебных данных.
- [schemas.py](schemas.py) — Проверяет входные JSON-данные через Pydantic до выполнения серверной логики.
- [security.py](security.py) — Проверяет пароли и сеансы, выдаёт JWT и записывает связанную HMAC-цепочку аудита.
- [serialization.py](serialization.py) — Преобразует объекты БД в данные ответа API, пригодные для JSON.
- [superapp.py](superapp.py) — Добавляет маршруты модулей суперприложения: совместную работу, учебные разделы и связанные записи.
- [superapp_models.py](superapp_models.py) — Описывает дополнительные таблицы суперприложения: документы, задачи, сообщения и связанные записи.
- [workspace.py](workspace.py) — Предоставляет операции рабочего пространства расследования и связанных документов.
