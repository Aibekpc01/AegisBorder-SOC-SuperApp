## 1. Итог в трёх строках

- **Функциональность зрелая и покрыта тестами**: 166 серверных тестов и 32 клиентских проходят, ESLint и TypeScript без ошибок. Бизнес-логику переписывать не нужно.
- **Главная слабость — визуальный слой**: 25 CSS-файлов, 12 из них глобальные и подключаются друг поверх друга; 818 цветов заданы вручную; токены разбросаны по трём пространствам имён. Отсюда неровные отступы, «плавающие» размеры шрифтов и заплатки для светлой темы.

## 3. Архитектура

```
Браузер ──► FastAPI (app/command/api.py + 8 роутеров)
             ├─ middleware guard: лимиты записи, проверка Origin, заголовки безопасности
             ├─ /api/v1/*  REST + WebSocket /api/v1/ws (cookie-сессия)
             └─ /{path}    SPA: отдаёт app/web/index.html (сборка Vite)
React: main.tsx ─► "/" → Landing (лениво)
                 └► всё прочее → CommandCenter (лениво) ─► 29 разделов /app/*
```

Серверные модули (`app/command/`): `api` (ядро: вход, события, инциденты, отчёты, WebSocket), `detection` (правила), `analytics` (аномалии), `scenarios` (генератор синтетики), `workspace` (документы и версии), `superapp` (задачи, почта, двойник, академия, конструкторы), `connectors` (приёмники интеграций), `presence` (устройства и сотрудники), `governance` + `rbac` (роли и иерархия), `dlp` + `dlp_gate` (локальный DLP-агент), `profiles`, `news`, `security`, `reports`.

### 6.4. Безопасность

Сильные стороны (сохраняются): Argon2, `HttpOnly + SameSite=Strict + Secure (при HTTPS)` cookie, лимиты входа по IP и логину, лимит записи 120/мин, проверка `Origin` для изменяющих запросов, `X-Frame-Options: DENY`, `nosniff`, `Referrer-Policy`, `no-store` для API, серверная иерархия ролей, журнал аудита с проверкой целостности, секреты только в `.env`, отсутствие внешних ресурсов, `dangerouslySetInnerHTML`/`eval` не используются.

| # | Замечание | Риск | Решение |
|---|---|---|---|
| S1 | Нет `Content-Security-Policy` | Средний (защита в глубину от XSS) | Добавить строгую CSP без внешних источников |
| S2 | Нет `Permissions-Policy` | Низкий | Разрешить только `geolocation=(self)`, остальное запретить |
| S3 | Нет `Strict-Transport-Security` при HTTPS | Низкий | Отправлять HSTS только для HTTPS |
| S4 | В корне лежат файлы, не предназначенные для репозитория: `diagnostics_backup/` (логи WinDbg, экспорт фаервола), `PC-Setup-*`, AST-дамп, бинарный `AegisDLP.exe`, `tatus --short` | Утечка сведений о рабочей машине при публикации | Исключены через `.git/info/exclude`; рекомендуется удалить вручную |
| S5 | 12 мест с `any`/`eslint-disable` во фронтенде; `Row = Record<string, any>` | Технический долг | Не менять контракт `api.ts` в этой итерации, описать в плане |

## 7. План работ (минимальный риск регрессий)

1. **Design system**: один файл токенов `styles/tokens.css` (цвет, типографика, отступы, радиусы, тени, движение, обе темы) + сопоставление прежних переменных `--ultra-*`, `--sa-*` с новыми, чтобы старые компоненты сразу получили новую палитру.
2. **Слой системы** `styles/system.css`, подключаемый последним: оболочка, боковая и верхняя панели, кнопки, поля, таблицы, карточки, бейджи, диалоги, пустые состояния, фокус, reduced motion. Только визуальные свойства; классы и разметка компонентов не меняются.
3. **Исправление дефектов V1–V7** вёрсткой, без изменения логики.
4. **Главная страница**: новая композиция Hero → Возможности → Интерактивный пример → Польза → Технологии и надёжность → Призыв к действию. Все существующие блоки и ссылки сохраняются. Анимированная сцена — лёгкий SVG + CSS без Three.js (не утяжеляем бандл, уважаем `prefers-reduced-motion`).
5. **Производительность**: WebP вместо PNG в размерах вывода, ленивый помощник по сайту, долгий кэш для `/assets/*`.
6. **Безопасность**: CSP, Permissions-Policy, HSTS при HTTPS; серверный тест на заголовки.
7. **Проверка**: pytest, Vitest, ESLint, `tsc`, сборка, скриншоты до/после на 1920/1366/768/390, измерение метрик загрузки.
8. **Документация** для конкурса.

Не выполняется без отдельного согласования: изменение схемы БД, API, ролей; переименование бренда; удаление файлов пользователя; развёртывание.
