# AegisBorder SuperApp

Веб-система для обнаружения и расследования **синтетических** киберинцидентов и обучения сотрудников: события → объяснимые правила → инцидент → расследование → PDF-отчёт. Работает в закрытой сети, решение принимает человек.

**Стек:** FastAPI · SQLAlchemy · PostgreSQL 16 · Alembic · React 19 · TypeScript · Vite · TanStack Query · Tiptap · Playwright.

## Быстрый запуск

Полный проект на постоянной VM: [инструкция Oracle Cloud Always Free](docs/oracle-deploy.md). Конфигурация `compose.oracle.yaml` включает приложение, PostgreSQL и HTTPS; секреты создаются на сервере.

Запустите Docker Desktop с Linux-контейнерами. Существующий `.env` сохраняйте. В новой установке заполните значения из `.env.example`: DB_PASSWORD, ADMIN_PASSWORD (≥12 символов), AUDIT_KEY (≥32).

```powershell
docker compose up --build -d --wait --wait-timeout 240
docker compose ps
curl.exe http://127.0.0.1:8000/api/v1/health
```

Открыть **http://127.0.0.1:8000** — публичная учебная главная страница. Рабочая панель: **http://127.0.0.1:8000/app**, комиссия: **http://127.0.0.1:8000/app/commission**, документы: **http://127.0.0.1:8000/app/workspace**. Вход: `admin` и ваш действующий пароль (при первоначальном создании — ADMIN_PASSWORD). Для повторных запусков — `Запустить.bat`. Остановка: `Остановить.bat` или `docker compose down`. Флаг `-v` удаляет базу; не используйте его для обычной остановки.

## Что реализовано

Новый этап: интерактивная история защиты с портретами и объяснениями 21 модуля, честная анимация загрузки, автоматическая геолокация с разрешением браузера и защищённые корпоративные приёмники. Инструкции: [интеграции](docs/corporate-integrations.md), [бесплатная публичная демонстрация](docs/public-demo.md), [иллюстрации и промпты](docs/story-assets.md).

- [Демонстрация, обучение и команда](docs/presentation-and-learning.md): интерактивный показ проекта, 12 учебников, слайды всех разделов, скачиваемые материалы и чат участников.

- [Первое знакомство без IT-подготовки](docs/first-visit.md): простой режим, пояснения к каждому разделу, словарь, формы без JSON и пошаговый показ.

- [Учебный релиз SuperApp](docs/superapp-local-release.md): задачи, импорт JSON/CSV, почтовый анализ, цифровой двойник, черновик расследования, академия, конструкторы правил и личных сценариев, мониторинг импортированных Microsoft 365-событий.
- [Пакет для запуска без сети](docs/offline-release.md) и [восстановление администратора](docs/admin-recovery.md). Внешние подключения и LLM не настроены.

- SuperApp: публичный лендинг с явно обозначенным учебным примером, рабочая область `/app`, сохранённые прежние ссылки, глобальный поиск, список незакрытых инцидентов, тёмная и дополнительная светлая тема.
- [Workspace](docs/workspace.md): Tiptap, шаблоны, таблицы, автосохранение в базе, история версий, заметки, ответственный, статусы, RBAC, контроль целостности и защита от конфликтов редактирования.
- [Аудит и восстановление](docs/SUPERAPP_AUDIT.md), локальный Git-тег `superapp-baseline`, ветка `feature/superapp-redesign`.

- React, TypeScript, Vite, Tailwind, компоненты shadcn/ui на Radix, Lucide, Recharts, React Router и TanStack Query.
- 14 русскоязычных разделов Command Center, простой и технический режимы.
- FastAPI, SQLAlchemy, миграции Alembic, PostgreSQL; отдельный SQLite-режим без Docker.
- Argon2, JWT в HttpOnly-cookie, отзыв сеансов, роли и ограничения доступа API.
- 15 различных учебных ситуаций, единый обработчик, временные окна, дедупликация и объяснимый риск.
- Статусы, ответственный, комментарии, доказательства, расследование, история и PDF.
- Собственные демонстрационные сеансы и пошаговый режим комиссии.
- HMAC-аудит и WebSocket-уведомления о новых сохранённых данных.
- Профили с фото и личными полями, приватная история IP-входов и добровольная геолокация браузера.
- Инструкции под рабочими блоками и настраиваемая политика IP/VPN-доступа; [возможности и ограничения](docs/profiles-and-network-access.md).
- Отдельный Isolation Forest на явно обозначенном синтетическом профиле, без вымышленных показателей точности.

Генераторы создают события, а результаты рассчитывает сервер. При изменении правил результаты меняются. Состояние учётных записей, правил, инцидентов, расследований, сеансов и отчётов сохраняется в БД.

Прототип v0.2 сохранён в `app/legacy_main.py` и `app/static/index.html`; его таблицы не удалены. Новая версия использует `cc_`. Перед обновлением этой сессии создан `backup-before-command-center.dump`, исключённый из Git.

## Без Docker

```powershell
python -m venv .venv
.venv/Scripts/python.exe -m pip install -r requirements.lock-windows.txt
powershell -NoProfile -File scripts/build_local.ps1
.venv/Scripts/python.exe scripts/start_local.py
```

Скрипт читает `.env`; без DATABASE_URL использует `aegisborder_local.db`. Docker и локальный сервер не должны одновременно занимать порт 8000. Для отдельной проверки можно передать `--port 8001`.
